# TNU Tech Community

A static student technology community website for the Faculty of Engineering, Tanta University.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Six independent technical teams
- Team details and learning roadmaps
- Search and category filtering
- Arabic / English language switch
- Light / Dark theme
- Responsive design
- No backend required

## Run locally
Open `index.html` in your browser.

For a better local development experience, use VS Code Live Server.

## Deploy to Vercel
1. Push the project to a GitHub repository.
2. Import the repository into Vercel.
3. Select Other as the framework preset if asked.
4. Leave Build Command empty.
5. Set Output Directory to `.`.
6. Deploy.

No build command is required.
